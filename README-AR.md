# موقفي — حزمة النشر على Vercel

هذه حزمة الموقع الجاهزة للنشر، إصدار 9.0.0: شاشة تحميل بشعار CMC متجه وشفاف بلون واحد، ثم واجهة مطورة بلا خريطة، تفحص جودة GPS وتوضح هامشه وترفض القراءات القديمة والشاذة، ثم تعرض الموقف المقترح، المسافة ومدة المشي فقط بالدقائق، وموعد الحافلة التقديري. لا تظهر ساعة وصول الشخص ولا تتغير مدة المشي لمجرد تغير الساعة. الجدول الصباحي المقدم 07:30–08:00 ومدته 30 دقيقة.

## النشر

1. فكّ ضغط الأرشيف.
2. افتح مجلد `mawqifi-vercel` الذي يحتوي مباشرةً على `vercel.json` و`public`.
3. انشر هذا المجلد، وليس ملف ZIP نفسه ولا مجلد `public` منفردًا.

### باستخدام أداة النشر

إذا كان Node.js مثبتًا على جهازك، افتح الطرفية داخل `mawqifi-vercel` ونفّذ:

```bash
npx vercel login
npx vercel --prod
```

تسجيل الدخول يتم في حسابك؛ لا تحتاج الحزمة إلى مفاتيح API أو متغيرات بيئة.

### بالنشر من مستودع Git

ارفع **محتويات** مجلد `mawqifi-vercel` إلى جذر المستودع، ثم اربطه بمشروع Vercel. يجب أن يكون `vercel.json` في جذر المشروع المختار.

الإعدادات مضبوطة في الملف:

| الإعداد | القيمة |
| --- | --- |
| Framework Preset | Other |
| Root Directory | المجلد الذي يحتوي `vercel.json` |
| Build Command | فارغ — لا توجد خطوة بناء |
| Install Command | فارغ — لا توجد حزم لتثبيتها |
| Output Directory | `public` |

**لا تضف `npm run build` أو أمر Python.** الموقع مبني مسبقًا، ولا يحتاج `package.json` أو `node_modules`.

## ماذا تحتوي الحزمة؟

- `public/index.html`: التطبيق كاملًا دون خريطة مرئية، بما فيه الخطوط والأكواد وشبكة المشي وتقديرات الحافلة. واجهة الإصدار التاسع تتبع اتجاه «لوحة الحرم»: أرضية طباشيرية، حبر صنوبري مؤسسي، وبرتقالي مقتصد لا يكسبه إلا التقدير أو التنبيه.
- `public/sw.js` و`manifest.webmanifest` والأيقونات: الإضافة للشاشة الرئيسية والعمل دون اتصال بعد أول تحميل ناجح.
- `public/data/`: البيانات العامة بصيغ قابلة للقراءة آليًا، لإتاحة المصادر والالتزام بتراخيص بيانات الخرائط. التطبيق لا يطلب هذه الملفات أثناء التشغيل؛ ما يحتاجه للحساب مضمن في `index.html`، ومنها `arrival-estimates.json` المميز بوضوح كتقديرات غير رسمية.
- `public/LICENSE.txt` و`THIRD-PARTY-NOTICES.txt` و`licenses/`: تراخيص الكود والخطوط والمكتبات وبيانات الخرائط؛ أبقها عند النشر.
- `vercel.json`: إعدادات الاستضافة وترويسات السماح بموقع الهاتف.

لا تحتوي الحزمة على ملفات البحث أو الاختبارات أو النسخ القديمة أو بيانات حساب Vercel أو أي توكن. وهي حزمة نشر، وليست مجلد التطوير الكامل. تعديل ملفات JSON الخارجية وحدها لا يغيّر بيانات الصفحة المضمّنة؛ استخدم حزمة المصدر الأصلية لإعادة البناء عند تعديل البيانات.

## تحسينات الإصدار التاسع

أعاد الإصدار التاسع بناء السطح كله على اتجاه «لوحة الحرم»: مسطرة قياس تحت الأرقام الثلاثة، وسم مصدر لكل رقم (محسوب / من الجدول / تقديري)، ومفتاح قراءة دائم، ونافذة منهجية. بقيت مقارنة المواقف القريبة، وقائمة المواقف الإحدى عشرة، ونافذة تحسين إشارة GPS، وزر إضافة للهاتف، ومشاركة معلومات الموقف دون إحداثيات الهاتف أو المسافة الشخصية. لا توجد ساعة وصول للشخص؛ المدة بالدقائق فقط.

القراءة الأولى لا تعني استقرارًا مؤكدًا. الحد التلقائي 50م، والتحديد الأضعف يحتاج قبولًا صريحًا. يُفحص أثر هامش GPS بثماني عينات؛ هذا فحص محدود وليس ضمانًا لدقة النقطة أو الموقف. لا يغيّر الموقع قدرة الهاتف أو يحوّل المواقع التقديرية إلى إحداثيات ميدانية معتمدة.

## شاشة التنزيل عند الدخول

تظهر الهوية ثم يتقدم الحفظ حسب عدد الملفات العامة المحفوظة من 7، لا حسب عدّاد زمني وهمي أو تقدير بايتات. تُفتح الصفحة تلقائيًا بعد الحفظ والتهيئة، ثم يُطلب GPS. عند العودة تُستخدم الملفات المحفوظة دون إعادة تنزيلها. إذا فشل الحفظ يمكن إعادة المحاولة أو المتابعة دون ادعاء Offline جاهز.

الشعار والأيقونات SVG بمسارات فعلية وخلفية شفافة؛ صور PNG بدائل للأيقونات فقط. حقوق الشعار لأصحابه وهو مستخرج من صورة المستخدم، وليس ملفًا رسميًا متجهًا أو اعتمادًا رسميًا للتطبيق.

## بعد النشر

افتح رابط HTTPS في تبويب مستقل بمتصفح الهاتف واسمح بتحديد الموقع. إذا تعذّر GPS، يظل اختيار موقف يدويًا متاحًا لمعرفة موعد الحافلة فقط، دون اختلاق مسافة أو مدة مشي للشخص. النشر يحتاج إلى صلاحيات مناسبة في حساب Vercel؛ هذه الحزمة لا تتجاوز قيود الحساب ولا تعني أن الموقع نُشر تلقائيًا.

مواضع الوقوف والمسافة ومدة المشي تقديرية. مواعيد الحافلة الوسيطة موزعة حسب المسافة بين 07:30 و08:00، دون معرفة التوقفات والتأخير؛ ليست جدولًا معتمدًا أو تتبعًا حيًا. لا يُختلق وقت وصول الرجوع أو أيام تشغيل. جميع الساعات بتوقيت Africa/Casablanca. بيانات الموقع الشخصية لا تُرفع إلى خدمة توجيه ولا تُحفظ في ملفات الموقع.
